# MISSION CONTROL — wydania

To repozytorium zawiera wyłącznie instalatory aplikacji MISSION CONTROL dla Windows,
publikowane jako GitHub Releases. Aplikacja (wersja Setup) sama sprawdza tu nowe wersje
i proponuje ich pobranie. Kod źródłowy nie jest tu publikowany.

Pobierz najnowszy plik `Mission-Control-*-Windows-Setup.exe` z zakładki **Releases**.
Sumy SHA-256 są dołączone do każdego wydania.
